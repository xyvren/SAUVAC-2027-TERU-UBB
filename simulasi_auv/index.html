TRANSPORT Koneksi Konfigurasi Pico W

USB Serial menggunakan bridge laptop yang sudah ada. Wi-Fi memakai access point Pico W ber-password dan UDP 192.168.4.1:4210; sambungkan laptop ke SSID SAUVAC-XXXX (suffix dari MAC) menggunakan kredensial privat firmware terlebih dahulu. AP hanya aktif bila firmware dibangun dengan password WPA privat non-placeholder sepanjang 12–63 karakter. Server web/API tetap hanya mendengarkan loopback laptop.

Firmware/board: menunggu telemetry.
Persiapan OTA: firmware OTA-capable pertama kali tetap harus dipasang lewat USB/BOOTSEL. Setelah itu, firmware .bin dapat diteruskan dashboard melalui Python ke Pico W lewat Wi-Fi. File UF2 hanya untuk pemulihan BOOTSEL.
Wi-Fi belum diperiksa. Pilih Pico W Wi-Fi lalu baca konfigurasi.

Kanal Wi-Fi sekarang menyediakan parameter, terminal CLI aman, telemetri/status polling, kontrol motor, misi, kalibrasi, Auto-Run, dan emergency stop. Perintah HIL fisik tetap membutuhkan interlock USB/serial. Status koneksi adalah hasil readback terakhir, bukan substitusi watchdog USB.

Status firmware belum dibaca.

Pembaruan firmware lewat Wi-Fi

Python lokal hanya menjadi perantara upload ke endpoint OTA Pico W; kanal perintah UDP berhenti sementara saat perangkat menulis dan restart. Gunakan password AP Pico W yang sama.

Lepas propeler/isolasi thruster, pastikan perangkat idle dan disarmed serta Auto-Run nonaktif. Firmware memeriksa kondisi aman lagi sebelum menerima file. Jangan matikan daya selama upload.

Hubungkan dan baca status Pico W. Upload baru aktif saat idle, disarmed, dan Auto-Run nonaktif.

Perubahan pertama-tama ditahapkan. “Terapkan” mengubah konfigurasi aktif, “Simpan” menulis EEPROM, dan “Buang” memulihkan konfigurasi tersimpan. Perangkat harus idle dan disarmed.
